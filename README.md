# Amethyst-OS
Amethyst OS focuses on reliability, speed, and stability, all without the need for a fresh OS reinstall.
This was mostly made as I was tired of seeing people on X sell custom windows installations, that not only sacrifice system security, but end up just being broken and wasting your time.

Amethyst OS Does NOT Require a Windows reinstall, it applies our tweaks to your current installation of Windows 11.

# Installation Guide
- Download the latest Amethyst.OS.apbx here: https://github.com/ItsVyruss/Amethyst-OS/releases/tag/v1.0
- Download and open AME Wizard from https://amelabs.net/
- Drag Amethyst.OS.apbx into AME Wizard and follow the prompts.
- Choose Brave Browser (More options soon!)
- Restart when it's done.
